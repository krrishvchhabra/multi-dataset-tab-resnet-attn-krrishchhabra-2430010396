# Dataset Directory

Place downloaded datasets in this directory.

Raw datasets are not committed to Git by default.

## Expected dataset files

### Adult Census Income
adult.csv

### Bank Marketing
bank-additional-full.csv

### Default of Credit Card Clients
default_of_credit_card_clients.xls

### Covertype
covtype.data

See docs/dataset_sources.md for original sources and download guidance.

Ensure that each dataset is obtained from its original source and that
its license and terms of use are respected.
