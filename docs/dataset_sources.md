# Dataset Sources

Use the original dataset sources and follow their usage terms.

## Adult Census Income
UCI Machine Learning Repository:
https://archive.ics.uci.edu/dataset/2/adult

Target:
Income category (<=50K or >50K).

## Bank Marketing
UCI Machine Learning Repository:
https://archive.ics.uci.edu/dataset/222/bank+marketing

Target:
Whether the client subscribed to a term deposit.

Exclude duration from predictive features for a realistic
pre-call prediction setting.

## Default of Credit Card Clients
UCI Machine Learning Repository:
https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients

Target:
Default payment next month.

## Covertype
UCI Machine Learning Repository:
https://archive.ics.uci.edu/dataset/31/covertype

Target:
Forest cover type, seven classes.
